# رحّال V41 — إصلاح نهائي للخريطة

- تفعيل أزرار التكبير والتصغير فعليًا.
- تجربة OpenStreetMap ثم CARTO قبل الخريطة المحلية عند فشل المصدر.
- عند «عرض جميع الوجهات» يتم حذف المسار والتحديد وبطاقة الاختيار.
- «اختر من الخريطة» يعرض بطاقة الموقع داخل لوحة أدوات الخريطة تحت «تحديد موقعي» و«عرض جميع الوجهات».
- موقع المستخدم يظهر بنقطة زرقاء مخصصة.
- الوجهات تظهر بدبابيس حمراء مميزة.
- القائمة الجانبية تفتح من اليمين فوق الصفحة مع طبقة تعتيم ويمكن إغلاقها من الزر أو بالنقر خارجها.
- لا يحتاج Google Maps API Key.
