# رحّال V38 — Google Maps

هذه النسخة تضيف طبقة Google Maps إلى صفحة الخريطة مع إبقاء خريطة Leaflet المحلية كخطة بديلة.

## تفعيل Google Maps الحقيقي

1. أنشئ مشروعًا في Google Cloud.
2. فعّل **Maps JavaScript API** و **Places API (New)** للمشروع.
3. أنشئ API Key وقيّده باسم النطاق/التطبيق قدر الإمكان.
4. افتح `google-maps-config.js` وضع المفتاح في:

```js
window.RAHAL_GOOGLE_MAPS_API_KEY = 'ضع_المفتاح_هنا';
```

بدون المفتاح ستعمل صفحة الخريطة بخريطة رحّال البديلة الحالية.

## الوظائف المضافة

- خريطة عالمية Google Maps عند تفعيل المفتاح.
- بحث عن مدينة/دولة/معلم من داخل صفحة الخريطة.
- نقل الخريطة تلقائيًا إلى نتيجة البحث ووضع علامة عليها.
- حفظ نتيجة البحث كوجهة محلية داخل رحّال.
- تحديد الموقع الحالي.
- عرض جميع الوجهات بعلاماتها.
- الأقرب لموقعي.
- اختيار أي نقطة من الخريطة وحفظها كوجهة.
- خط أزرق من موقع المستخدم إلى الوجهة.
- حساب المسافة ووقت القيادة التقريبي عبر خدمة OSRM الحالية.

> ملاحظة: Google Maps وPlaces تتطلبان إعداد Google Cloud ومفتاح API عند الاستخدام الفعلي. تفاصيل Google الحالية حول البحث والتكملة موجودة في توثيق Google Maps Platform الرسمي.
