# رحّال V39 — إصلاح الخريطة

- إصلاح fallback الخريطة المحلية ليعرض العالم بدل مخطط اليمن فقط.
- زر **عرض جميع الوجهات** يمسح المسار الأزرق القديم والتحديد السابق.
- موقع المستخدم يظهر كنقطة زرقاء مخصصة بدل دبوس Leaflet الأزرق الافتراضي. Leaflet يستخدم الدبوس الأزرق افتراضيًا ويمكن استبداله بأيقونة مخصصة عبر `L.divIcon`.
- المسار لا يتم إنشاؤه تلقائيًا لمجرد فتح الخريطة بإحداثيات؛ يلزم اختيار/طلب مسار صريح.
- رفع مهلة الانتقال إلى الخريطة المحلية وتقليل التحويل المبكر بسبب أخطاء البلاطات.
- تحديث Service Worker إلى V39 حتى لا تبقى نسخة V37 مخزنة.
- لا يحتاج هذا الإصلاح إلى Google Maps API Key.
