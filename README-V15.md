# رحّال Explorer V15 — صور الوجهات الذكية

- عند اختيار نقطة من الخريطة يحاول رحّال التعرف على المدينة والدولة.
- يجلب صورة للمدينة أولاً من Wikipedia، ثم صورة الدولة، ثم Wikimedia Commons كحل احتياطي.
- الوجهات اليمنية الأساسية لها صور غلاف مناسبة بدل صورة placeholder.
- عند الحفظ تُخزّن صورة الوجهة واسم المدينة والدولة والإحداثيات والمسافة ووقت الوصول.
- تبقى واجهة رحّال الأصلية كما هي.
