# Rahal V64.3 — Nearest Destination Map Mode

- Removed the blue route line from the «الأقرب لموقعي» action.
- When «الأقرب لموقعي» is used, only the nearest destination marker remains visible alongside the user location.
- The nearest destination opens using the same Rahal destination card with its image, country, distance and estimated driving time.
- «عرض جميع الوجهات» restores all destination markers and clears the selected route state.
- Renamed «اختر من الخريطة» to «اختر وجهة» for clearer wording.
