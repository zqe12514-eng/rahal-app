# رحّال V23

تحسينات الخريطة والأداء:
- الخريطة تستخدم تحميلًا أكثر سلاسة مع التكبير حتى مستوى الشوارع.
- تحديد الموقع يعرض الموقع المحفوظ فورًا ثم يحدّثه من GPS.
- التكبير عند تحديد الموقع أصبح 17 لرؤية الشوارع بوضوح.
- بطاقة اختيار نقطة من الخريطة تظهر فورًا بدل انتظار الصورة أو المسار.
- المسار الأزرق يظهر فورًا كمسار تقريبي، ثم يُستبدل بمسار الطرق الحقيقي عند توفره.
- تم وضع مهلة 6 ثوانٍ لخدمة حساب مسار الطرق حتى لا تتجمد الواجهة.
- أزيل البحث البطيء عن صور عشوائية من Wikimedia عند اختيار أي نقطة؛ الصور المعروفة فقط تُحمّل مباشرة.
- بطاقة المكان أصبحت داخل الخريطة ومقروءة بوضوح.
