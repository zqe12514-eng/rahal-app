# Rahal V22

التحديثات:
- تحسين بطاقة اختيار نقطة من الخريطة: صورة أكبر، نص واضح، وتخطيط مناسب للوضع الليلي والنهاري.
- إذا فشلت صورة نقطة مختارة لا يظهر رمز/صورة مكسورة؛ يظهر بديل واضح.
- زر تحديد موقعي يعمل داخل خريطة رحّال.
- زر الاتجاهات في تفاصيل الوجهة يفتح خريطة رحّال الداخلية ويعرض المسار من موقع المستخدم عند توفره.
- إضافة زر لغة بجانب زر الإضاءة في الشريط العلوي.
- العربية هي اللغة الافتراضية، وزر EN يحول الواجهة إلى الإنجليزية، وزر ع يعيدها للعربية.
- أسماء المدن والدول والتصنيفات وبطاقات الوجهات تتبع اللغة المختارة.
- حفظ اللغة في الجهاز حتى تبقى بعد فتح الصفحات مرة أخرى.
