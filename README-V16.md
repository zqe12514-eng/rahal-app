# رحّال Explorer V16
- حساب مسافة الطريق الفعلية من آخر موقع محفوظ إلى أي وجهة.
- رسم خط أزرق لمسار الطريق على الخريطة داخل رحّال عند الضغط على «احسب المسافة من موقعي».
- عرض المسافة ووقت القيادة التقريبي.
- فتح نفس المسار في Google Maps عبر زر واضح.
- عند تحديد نقطة من الخريطة، تبقى بطاقة الدولة/المدينة والصورة والحفظ كما هي.

ملاحظة: خريطة رحّال داخل التطبيق تستخدم OpenStreetMap/Leaflet لأن عرض Google Maps التفاعلي داخل التطبيق يحتاج Google Maps API Key. Google Maps متاح كمسار خارجي رسمي من الأزرار.
