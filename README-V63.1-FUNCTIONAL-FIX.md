# Rahal V63.1 — إصلاح وظيفي وأداء

- رحلاتي: عرض الوجهة أولًا بدل بطاقات الإفطار/الانطلاق/المعلم، مع روابط تفاصيل الوجهة والصور.
- إزالة خيارات المسار من بطاقات الوجهات والاختيار العادي على الخريطة.
- المسار والاتجاهات يبقيان مرتبطين بخيار «الأقرب لموقعي» فقط.
- منع الفتح التلقائي للمسار عند فتح وجهة عبر رابط الخريطة.
- تحسين خريطة الوجهات: تحميل البلاطات عند الخمول وتقليل الاحتفاظ بالبلاطات.
- Service Worker: تقديم الملفات المخزنة فورًا مع تحديثها في الخلفية لتقليل الدوران عند التنقل.
- الثيم محفوظ عبر localStorage ومطبق مبكرًا على الصفحات.
